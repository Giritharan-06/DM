# Premium website theme

The public website now uses warm ivory, ink navy, coral and muted green. The previous horizontal scroll rail has been replaced by a pinned three-chapter studio sequence on large screens. Mobile and reduced-motion views show every chapter as regular content. Inactive pinned chapters are inert so keyboard focus stays in the visible chapter.

Business goals update a suggested service direction. The mobile menu exposes services, expertise, plans, industries, work, FAQ and contact. The floating contact button opens WhatsApp when a number is configured, or a native accessible contact dialog otherwise. Decorative social platform icons are labeled as channels; agency profile links appear only when configured.

CRM Settings → Public website & social links controls email, phone, WhatsApp, Instagram, Facebook, LinkedIn, YouTube, booking URL and floating-contact visibility. The owner-only API validates and audits changes. Public rendering reads the database on each page request and exposes only validated public fields. Blank saved links hide them. Neon configuration is still required to verify persistence live.

Three assets were generated with the built-in imagegen tool. Original transparent PNGs and optimized WebP versions are stored in apps/website/public/art/:

- premium-growth.png / premium-growth.webp
- premium-creative.png / premium-creative.webp
- premium-campaign.png / premium-campaign.webp

Designed to sit over an ink-navy background beside big cream typography.
